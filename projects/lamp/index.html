lamp — autodiff en Rust

lamp est un moteur minimal d’auto‑diff en Rust. Idées clés : Tensor (données + shape/strides/offset), Trace/Node (DAG), VJP pour la rétroprop, broadcasting explicite, et ops linéaires (matmul 2D/batch).

RustAutodiffML

Installation

Projet en développement privé. Clone :

git clone git@github.com:Hykrow/engine_rs.git
cd engine_rs
cargo build

Exemple rapide

Un MLP simple sur MNIST‑like, avec calcul de gradient (style JAX) :

let (loss, grads) = value_and_grad(¶ms, |tr, pids| {{
    let x = tr.input(xb.clone());
    let y = tr.input(yb.clone());

    let mut cur = ParamCursor::new(pids);
    let l1 = Linear::bind(&mut cur);
    let l2 = Linear::bind(&mut cur);
    let l3 = Linear::bind(&mut cur);

    let h1 = l1.apply(tr, x);
    let z1 = relu(tr, h1);
    let h2 = l2.apply(tr, z1);
    let z2 = relu(tr, h2);
    let o  = l3.apply(tr, z2);

    mse(tr, o, y)
}});

value_and_grad crée une trace, exécute le forward, puis remonte les VJP pour récupérer les gradients des paramètres.

Design

  • Tensor : stockage contigu, shape, strides, offset, vues (squeeze/unsqueeze).
  • Trace / Node : chaque op pousse un Node avec ses parents et une fermeture vjp (SmallVec pour l’alloc minimale).
  • Broadcasting : règles explicites et somme des gradients sur les axes broadcastés.
  • Ops : matmul 2D/batch, add, sub, hadamard, relu, mse.

Roadmap

  • Optimiseurs : SGD/Adam, weight decay.
  • Conv2d, pooling, normalisations.
  • Dataloader générique (collate custom, shuffle, drop_last optionnel).
  • GPU (expérimental) : backends wgpu/CUDA.
  • APIs style JAX : jit/vmap (tracing + IR).
  • Plus de tests unitaires (sans modules intégrés selon la préférence).
