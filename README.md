# Site GitHub Pages — Noam Fauverte

Starter prêt à publier pour un site **username.github.io** (Pages).
Langue : **français**, design minimal, thème light/dark, et page projet **Rust _lamp_**.

## Déployer

1. Crée un dépôt nommé **&lt;ton-username&gt;.github.io** sur GitHub.
2. Mets ces fichiers à la racine du dépôt (le dossier `assets/` et `projects/` compris).
3. Dans *Settings → Pages*, choisis **Source: Deploy from a branch** avec **Branch: main / root** (ou `master` selon ton dépôt).
4. Attends l’activation, puis visite `https://&lt;ton-username&gt;.github.io/`.

*(Optionnel)* Ajoute un domaine custom : crée un enregistrement CNAME et ajoute un fichier `CNAME` à la racine.

## Modifier le contenu

- **Accueil** : `index.html`
- **Styles** : `assets/style.css`
- **Script** : `assets/script.js`
- **Page lamp** : `projects/lamp/index.html`

## À personnaliser

- Liens de contact (email, LinkedIn).
- Sections projets additionnelles (TP CUBE, bird/mouse detection, etc.).
- Ajoute un favicon si besoin.
